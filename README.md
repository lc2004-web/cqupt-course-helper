# CQUPT 研究生选课辅助器 2.6.2（浏览器扩展版）

安装一次后，直接点击 Edge/Chrome 工具栏图标填写课程编号、开始监控或暂停，不需要反复打开开发者工具。

## 一键登录研究生在线

1. 打开扩展弹窗，在最上方输入统一认证码和统一认证密码。
2. 点击“一键登录研究生在线”。扩展会打开学校统一身份认证页面，填写官方表单并进入学校门户。
3. 认证成功后，扩展会在门户中识别并打开“研究生在线”。只有真正到达研究生在线页面，后面的培养方案、导入、去选课和监听功能才会解锁。
4. 若账号或密码错误、出现验证码/滑块验证，扩展会停留在登录页，不会重复提交或绕过验证。

可选择“记住账号和密码”。勾选后账密保存在本机扩展的 `chrome.storage.local` 中，下次打开扩展会自动填入；不勾选时密码只写入 `chrome.storage.session`，关闭浏览器后自动清除。可选启用学校登录页提供的“7天免登录”。

## 安装到 Microsoft Edge

1. 解压 `cqupt-course-helper-extension.zip`。
2. 在地址栏打开 `edge://extensions/`。
3. 打开左侧的“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择解压后的 `cqupt-course-helper-extension` 文件夹。
5. 将“CQUPT 研究生选课辅助器”固定到工具栏。

Chrome 的操作相同，扩展管理地址为 `chrome://extensions/`。

## 推荐：从培养方案快捷导入

1. 登录研究生管理系统，停留在系统内任意页面。
2. 点击工具栏上的扩展图标。
3. 点击“从培养方案导入”。扩展会按系统现有菜单打开“培养方案/培养计划”，并在页面右上角显示导入向导。
4. 在培养方案表格中勾选准备选择的课程；这一步不会由扩展提交培养方案。
5. 点击向导中的“导入已选课程”。扩展只读取已勾选行的课程编号并保存到本机，不会自动跳转；成功后会显示绿色确认窗口。
6. 导入成功后，在扩展的“教师与班级偏好”中为每门课程选择希望优先抢到的教师和教学班。偏好会自动保存到本机。
7. 点击“去选课”打开“课程网上选课管理”。
8. 确认当前已在选课管理页面，选课即将开放时点击“开始监听”；按钮会原位变为“停止监听”。
9. 扩展持续检查当前页面，并按设置的间隔刷新；发现可用班后优先选择偏好班。偏好班不可用时会选择其他可用班，最终提交仍需你手动确认。

## 手动填写课程编号

也可以不使用向导，直接在扩展中每行填写一个准确课程编号，例如：

```text
M0130005
M0150023
```

扩展按“课程编号完全相等”查找课程。只有一个匹配行时，会自动勾选安全的复选框；尚未显示选框时，会自动打开“选择上课班级”。最终提交仍需你手动点击。

## 设置说明

- `课程编号`：每行一个，自动转为大写并去重，只做精确匹配。
- `培养方案导入`：只读取已勾选课程行的编号并保存在浏览器本机，不会提交培养方案，也不会自动启动守候。
- `教师与班级偏好`：根据 2026-2027 学年第一学期排课表列出教师、班级、时间和地点。每门课程可设置一个优先班；未设置或偏好班不可用时仍会选择其他可用班。
- `低频自动刷新`：默认每 15 秒一次，并加入少量随机延迟；最低可设为 1 秒。
- `自动选中`：单班直接勾选；多班优先匹配已保存的班级名、教师、上课时间和地点，没有可用偏好时从其他可用班中选择。
- `刷新上限`：每次启动最多刷新 120 次，达到上限自动暂停。

## 安全边界

扩展不会自动点击包含“提交、确认、保存、立即选课、退选、删除、清空、撤销”的操作，也不会构造私有接口请求或绕过验证码、限流和学校规则。

系统菜单通过页面文字识别，不写死带 `EID` 的临时网址；如果学校改了菜单名称，向导会保留在右上角并提示手动进入对应页面。当前选课尚未开放，因此实际班级列表的 DOM 仍需在开放后核对一次。

扩展 1.3.1 起会在页面脚本尚未加载时主动注入并重试。点击导入后弹窗不会自动消失，状态区会明确显示“向导已显示”或具体错误。

1.4.1 修复培养方案“分组情况”单元格使用 `rowspan` 后，后续课程行列位置左移而只能读取每组第一门课程的问题。现在每一行都会独立识别课程编号，并据此校正课程名称、类型和状态列。

1.5.0 修复在培养计划页面直接启动守候的问题。“开始持续守候”会先查找当前窗口中已经打开的“课程网上选课管理”标签页：找到后自动切换并仅绑定该标签页；未找到时点击当前系统的选课菜单，等待选课页加载完成后再启动。培养计划页不会执行扫描、刷新或课程勾选。

1.5.1 修复某个旧标签页或内层框架不返回时一直停在“正在定位选课页”的问题。跨标签页识别改为并行、只从系统主页面递归读取同源 iframe，并设置 2.5 秒识别超时、5 秒注入超时。`DefaultN.aspx?EID=...` 是系统外壳地址，扩展会继续检查其内层页面，不再依赖地址栏直接显示课程页路径。

1.6.0 新增全局快捷导航：“打开培养方案”和“打开选课管理”可在研究生在线的任意页面使用。扩展优先使用当前标签页及其 `EID` 会话；当前页没有菜单时先回到 `DefaultN.aspx` 系统外壳，再等待菜单加载并完成跳转。“开始持续守候”也统一复用这条导航链路，到达选课页后才启动监听。

1.6.1 修复默认主界面只能在手动点开“服务”后跳转的问题。扩展现在只点击可见菜单，避免把预加载的隐藏菜单误判为成功；目标入口不可见时会先打开“服务”，保留待跳转状态，再自动点击“培养方案”或“课程网上选课管理”。

1.6.2 适配三级菜单结构：默认主界面会依次打开“服务”→“培养”→目标功能。每一级都只识别可见且可交互的入口，页面或 iframe 加载过程中持续保留最终跳转目标，最长等待约 20 秒。

1.7.0 将导入、导航和监听拆分为独立步骤：导入只保存课程编号并显示明显的成功窗口；“去选课”只负责打开选课管理；“开始监听”只在当前选课管理页启动，启动后同一按钮变为“停止监听”。

1.7.1 将导入成功提示升级为研究生系统页面最上层的居中大弹层，包含醒目的绿色对勾、导入数量和课程编号；显示约 4 秒后自动淡出。从扩展弹窗导入成功时会自动收起弹窗，让大页面提示立即可见。

1.8.0 在扩展首页加入统一认证码和密码输入框及“一键登录研究生在线”。扩展通过学校官方统一认证表单登录，再从门户打开研究生在线；未成功到达研究生在线时选课功能保持锁定。密码仅保存在本次浏览器会话中，错误登录不会自动重复提交，验证码和安全验证必须由用户手动完成。

1.8.1 修复统一认证账号登录页反复刷新的问题。“账号登录”标签只会在账号表单尚未显示且当前还未进入 `userNameLogin` 模式时点击一次；进入账号模式后直接填写并提交，不再重复触发标签页重载。

1.8.2 修复账号密码已填写但未自动点击登录的问题。学校页面包含多套隐藏登录表单并重复使用控件 ID，新版将账号、密码和登录按钮严格限定到 `#pwdFromId` 账号密码表单；常驻但空白的滑块容器不再被误判为正在验证，只有验证码或滑块控件实际出现时才暂停自动提交。

1.9.0 登录表单填写完成后固定自动点击一次学校登录按钮，不再在提交前检查验证码或滑块容器；学校需要验证时仍由官方页面在提交后显示。新增“记住账号和密码”选项，勾选后账密保存在本机扩展数据中，下次可直接一键登录；仍保留单次提交锁，避免错误页面无限刷新和重复提交。

1.9.1 适配学校门户“我的服务”区域中的“研究生在线”卡片。登录进入门户后，扩展会在主页面、同源 iframe 和开放的 Shadow DOM 中精确查找“研究生在线”，向上定位真实可点击卡片并打开；等待窗口延长到 60 秒，到达研究生在线后再解锁原有选课功能。同时移除未登录界面的黄色解锁提示。
